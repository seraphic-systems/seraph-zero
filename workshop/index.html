05 / Textbox

A place to put a thought

Hover lights the RGB frame; focus opens the angel. The writing stays crisp. This is a visual study, with no storage; text resets on reload.

System reduced-motion preferences are always respected.

04 / Angel procession

From a point, into wings

Point → Seraph → Cherub → Throne, then back again. A repeating journey while we wait; the position does not represent a percentage.

08 / Christogenesis

All things, converging

Matter gathers into a living sprout; branching thought becomes a connected web; light gathers around Christ Omega. An artistic reading of Pierre Teilhard de Chardin’s Christogenesis. Each loading cycle moves forward, rests, and begins anew; position does not measure completion.
