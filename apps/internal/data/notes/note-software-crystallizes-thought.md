Prose gives an idea room to remain fluid. Code makes a choice explicit and enforceable: fuzzy → legible → encoded → enforced.

The important decision is when to crystallize. Faster implementation is useful only if the idea has had enough time to develop; otherwise speed locks in an assumption before it has been considered.
